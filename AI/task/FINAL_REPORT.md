## 4. 실험 결과

### 4.1 평가 지표
- **MAE** (Mean Absolute Error): 평균 절대 오차 (단위: g 또는 cm³)
- **MAPE** (Mean Absolute Percentage Error): 평균 절대 백분율 오차 (단위: %)
- **RMSE** (Root Mean Square Error): 평균 제곱근 오차 (큰 오차에 민감)
- **500g 이상 오차 비율**: 실용적 관점에서 큰 오차 발생 빈도

## 5. 실패한 방법

### 5.1 카테고리 예측 기반 스케일 보정
- **스크립트**: `evaluate_mast3r_category_scale.py`
- **방법**: 분류기로 카테고리 예측 → 해당 카테고리 평균 부피로 스케일 보정
- **결과**: MAPE 99.9% (실패)
- **원인**: 분류기 정확도 부족 (70% 이하), 잘못된 카테고리로 스케일 보정 시 오차 증폭

### 5.2 GPT + 카테고리 예측 조합
- **스크립트**: `evaluate_gpt_with_category.py`
- **방법**: GPT가 먼저 카테고리 예측 → 해당 카테고리 통계 참조
- **결과**: 카테고리 예측 오류로 인한 성능 저하
- **원인**: GPT의 Mercari 카테고리 체계 이해 부족

### 5.3 대분류만 사용한 스케일 보정

- **원인**: 대분류 내 제품 크기 편차가 커서 평균값이 부정확

## 6. 결론 및 권장사항

### 6.1 최적 방법 요약

| 목표 | 최적 방법 | 성능 | 비고 |
|------|----------|------|------|
| **무게 MAE 최소화** | GPT + v3 (카테고리 평균) | MAE **428g** | 절대 오차 최소 |
| **무게 MAPE 최소화** | MASt3R + GT Category | MAPE **96.2%** | 비율 기반 |
| **부피 MAPE 최소화** | GPT + Few-Shot | MAPE **98.7%** | Few-Shot 효과 |

### 6.2 핵심 발견사항

1. **Few-Shot Learning 효과**
   - 무게: 성능 악화 (129% → 186%)
   - 부피: 성능 개선 (217% → 99%)
   - **결론**: Few-Shot은 부피 예측에만 효과적

2. **카테고리 정보 활용**
   - 정답 카테고리 입력 시 성능 향상
   - 소분류 평균값이 대분류보다 정확
   - 카테고리 예측 오류 시 성능 악화

3. **MASt3R vs GPT**
   - MASt3R: 일관된 MAPE (~96%), 절대 스케일 추정 불가
   - GPT: MAE 더 낮음 (428g), MAPE 변동 큼

4. **데이터셋별 차이**
   - 물류센터: 큰 무게 범위 (2g ~ 16kg), 500g 오차 36%
   - Mercari: 소형 제품 위주, 500g 오차 10-30%

### 6.3 권장 사항

#### 실제 서비스 적용 시:
1. **카테고리 정보가 있는 경우**: GPT + 카테고리 평균 참조 (v3) 권장
2. **카테고리 정보가 없는 경우**: MASt3R + Image2Mass 사용
3. **부피 예측 필요 시**: GPT + Few-Shot 방식 권장

#### 추가 개선 방향:
1. 카테고리 분류기 정확도 향상 (현재 70% → 90%+)
2. 소분류별 통계 데이터 확충
3. 이미지 품질/각도에 따른 예측 신뢰도 추정
