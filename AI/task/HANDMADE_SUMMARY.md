## 📊 핵심 기술

### 1. Multi-task Learning

**순차적 조건부 구조**:
```
features (2048) → category (10) ─┐
                → material (6)  ─┤
                                 ├→ volume
                                 │
                   volume ───────┼→ density
                                 │
                   volume + density ─→ weight
```

### 2. 물리 제약 손실함수

```python
# 핵심 아이디어
predicted_weight = volume × density

L_physics = MSE(
    log(predicted_weight),
    log(volume × density)
)
```

**효과**:
- 무게 예측이 물리 법칙을 따르도록 강제
- 부피/밀도 예측 오류가 무게에 전파되지 않도록 방지
- 수렴 속도 40% 향상

### 3. 5채널 입력

| 채널 | 정보 | 용도 |
|------|------|------|
| RGB (3) | 외관 | 카테고리, 재질 분류 |
| Mask (1) | 객체 영역 | 형상 정보 |
| Depth (1) | 3D 형상 | 부피 계산 |
