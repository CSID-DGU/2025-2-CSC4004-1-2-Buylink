## 1. 프로젝트 개요

### 1.1 목표
제품 이미지로부터 무게(g)와 부피(cm³)를 자동으로 예측하는 시스템 개발

### 1.2 사용 데이터셋
1. **한국 물류공간 예측 데이터** (AI Hub)
   - 경로: `/home/2020112534/47.물류공간_예측_데이터/`
   - 카테고리: 가공식품, 일상용품, 패션잡화, 디지털/가전 등
   - Ground Truth: 3D 바운딩박스 기반 정확한 치수/무게

2. **Mercari Japan 데이터** (크롤링)
   - 경로: `/home/2020112534/task/nongpt/mercari/dataset_v5_organized/`
   - 카테고리: コスメ・美容, 生活家電, キッチン用品 등
   - Ground Truth: 제품 스펙에서 추출한 실제 무게/부피

### 1.3 평가 지표
- **MAPE (Mean Absolute Percentage Error)**: 평균 절대 백분율 오차
- **MAE (Mean Absolute Error)**: 평균 절대 오차 (g 또는 cm³)
- **RMSE (Root Mean Square Error)**: 평균 제곱근 오차
- **500g+ 오차율**: 500g 이상 틀린 샘플의 비율 (실용적 배송 지표)

## 4. 핵심 발견 및 인사이트

### 4.1 GPT 사전지식의 효과
- GPT-4o는 많은 소비재 제품의 스펙을 이미 알고 있음
- "알고 있으면 바로 답하라"고 명시적 지시 시 성능 향상
- 확신도 기반 하이브리드 전략이 효과적

### 4.2 카테고리 정보의 활용
- 카테고리 평균은 기본 baseline으로 유용
- 너무 세분화된 카테고리는 오히려 매칭 오류 유발
- GPT가 모를 때 fallback으로 활용하는 것이 최적

### 4.3 Few-Shot Learning의 한계
- 잘못된 예시가 오히려 성능 저하
- 대형 가전제품에서 극단적 오차 유발
- 신중한 예시 선정 필요

### 4.4 3D 복원 기반 방법의 한계
- MASt3R, MiDaS 모두 절대 스케일 복구가 핵심 병목
- 단일 이미지로는 실제 크기 추정에 근본적 한계
- 참조 객체 또는 카테고리 정보 필수

### 4.5 Web Search API 부적합
- 이미지 기반 제품 식별에 불안정
- JSON 응답 형식 불일치 문제
- 현재로서는 실용성 낮음
